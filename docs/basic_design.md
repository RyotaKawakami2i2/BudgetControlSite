# タスク・作業時間管理Webサイト 基本設計書

## 1. システム構成
- フレームワーク: ASP.NET Core MVC（.NET 8.0）
- フロントエンド: HTML5, CSS3, Bootstrap, JavaScript
- データベース: PostgreSQL（Docker）
- インフラ: Linux（WSL2）
- メールサーバー: MailHog（Docker Composeで起動、開発用）

## 2. 画面一覧
| 画面ID | 画面名 | 概要 |
|--------|--------|------|
| TOP    | トップページ | システム概要・ログイン導線 |
| LOGIN  | ログイン画面 | ユーザー認証・パスワードリセット申請導線 |
| REGISTER | アカウント登録 | 未ログインでも誰でも登録可能。権限はUser固定 |
| FORGOT_PASSWORD | パスワードリセット申請 | メールアドレス入力・リセットメール送信 |
| RESET_PASSWORD | パスワード再設定 | 新パスワード入力・リセット処理 |
| DASH   | ダッシュボード | 進捗・ガントチャート・グラフ |
| TASK   | ジョブ管理 | ジョブの一覧・登録・編集 |
| TEAM   | チーム管理 | チームの作成・編集・メンバー管理 |
| TEAM_MEMBER | チームメンバー追加 | チームへのメンバー追加・削除（管理者・リーダーのみ） |
| USER   | ユーザー管理 | ユーザー情報の管理 |
| REPORT | レポート | PDF/Excel出力 |

## 3. 主要機能と画面遷移
- ログイン後、ダッシュボードへ遷移
- ジョブ管理画面からジョブのCRUD操作
- チームリーダーはチーム管理画面でメンバー予定入力・追加
- アカウント登録画面は未ログインでもアクセス可能。権限はUser固定
- パスワードリセット申請画面（ForgotPassword）からリセットメール送信
- リセットメールのリンクからパスワード再設定画面（ResetPassword）へ遷移
- 各画面からレポート出力・分析画面へ遷移可能

## 4. 権限設計
- 管理者: 全機能利用可（アカウント登録・チームメンバー追加含む）
- チームリーダー: 自チーム管理・メンバー予定入力・メンバー追加・アカウント登録
- 一般ユーザー: 自分のジョブ・作業時間管理

## 5. データベースER図（概要）
- users（ユーザー、パスワードリセット用トークン・有効期限含む）
- teams（チーム）
- team_user（チームメンバー）
- tasks（ジョブ）
- scheduled_times（予定）
- actual_times（実績）
- categories（カテゴリ）
- projects（プロジェクト）
- time_entries（作業記録）
- notifications（通知）

## 6. 外部インターフェース
- メール送信（SMTP: MailHog、パスワードリセット・通知）
- CSV/Excelインポート・エクスポート

## 7. 非機能要件
- セキュリティ: SSL, パスワードハッシュ, XSS/CSRF/SQLi対策
- パフォーマンス: ページロード2秒以内
- バックアップ: 日次
- レスポンシブデザイン
