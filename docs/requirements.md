# タスク・作業時間管理Webサイト 要件定義書（C# ASP.NET Core MVC版）

## 1. システム概要
ジョブごとの予定時間と実績時間、予定日程と実績日程を管理するWebアプリケーションをC# ASP.NET Core MVCで開発する。ユーザーはジョブを登録し、予定と実績を入力することで、進捗状況や時間の差異を分析できる。チームリーダーはチームメンバーの予定・実績も管理可能。

## 2. 技術スタック
- バックエンド: C# ASP.NET Core MVC（.NET 8.0）
- フロントエンド: HTML5, CSS3, Bootstrap, JavaScript
- データベース: PostgreSQL（Dockerコンテナ）
- 開発環境: Visual Studio 2022/Visual Studio Code + WSL2
- インフラ: Linux（WSL2）
- メールサーバー: MailHog（Docker Composeで起動、開発用）

## 3. 機能要件

### 3.1 認証・認可
- ユーザー登録（未ログインでも誰でも登録可能。登録ユーザーの権限は一般ユーザー(User)固定）
- ログイン/ログアウト
- パスワードリセット（メールによるリセット申請・再設定）
- パスワードポリシー（12文字以上、英大文字・小文字・数字・記号）
- ユーザーロール（管理者/チームリーダー/一般ユーザー）
- セッション管理

### 3.2 チーム管理
- チームの作成/編集/削除
- チームリーダーの設定
- チームメンバーの追加/削除（管理者またはリーダーが実行可）
- チーム情報の表示

### 3.3 チームリーダー機能
- チームメンバーの予定入力
- チーム全体のスケジュール管理
- チームメンバーの作業時間管理
- チーム全体の進捗管理

### 3.4 ジョブ管理
- ジョブの登録/編集/削除
- ジョブの階層構造（親ジョブ/サブジョブ）
- ジョブのステータス管理
- ジョブの優先度設定
- ジョブのカテゴリ/プロジェクト分類
- ジョブの担当者割り当て

### 3.5 スケジュール管理
- ジョブごとの予定日程の設定（開始日時・終了日時）
- 実績日程の記録
- カレンダー表示
- ガントチャート表示
- マイルストーン設定

### 3.6 作業時間管理
- ジョブごとの予定時間の設定
- 実績時間の記録（作業開始/終了・休憩時間）
- 作業時間の自動計算
- 時間入力の一括インポート（CSV/Excel）

### 3.7 分析・レポート
- ガントチャート（予定vs実績、依存関係）
- 作業時間分析（ジョブ・プロジェクト・担当者別）
- 進捗状況ダッシュボード
- レポートのエクスポート（PDF/Excel）

### 3.8 通知機能
- ジョブの期限アラート
- 作業時間超過通知
- メール通知（MailHog等のSMTPサーバーを利用）
- システム内通知

## 4. 非機能要件
- SSL/TLS対応
- パスワードのハッシュ化
- XSS/CSRF/SQLインジェクション対策
- レスポンシブデザイン
- パフォーマンス（ページロード2秒以内、同時接続20人程度）
- バックアップ（日次）
- 操作マニュアルの提供

## 5. データベース設計（概要）
- users（ユーザー情報、パスワードリセット用トークン・有効期限含む）
- teams（チーム情報）
- team_user（チームとユーザーの中間テーブル）
- tasks（ジョブ情報）
- scheduled_times（予定時間情報）
- actual_times（実績時間情報）
- categories（カテゴリ）
- projects（プロジェクト）
- time_entries（作業時間記録）
- notifications（通知）
- audit_logs（監査ログ）
